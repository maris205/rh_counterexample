# 研究总结条目模板

本文件是未来总结论文与阶段报告的可复用模板，不是已完成的研究结果。复制后填写；没有证据的字段保持“未评估”，不得默认 GO 或通过。编号和状态定义见[路线说明](COUNTEREXAMPLE_ROADMAP_2026-09-16.md)。

## 条目身份与状态

- 条目标题：〈具体问题〉
- 方向：〈RC:A1 / RC:A2 / RC:A3 / RC:A4；可列多个〉
- 线索/对象编号：〈唯一编号〉
- 当前节点：〈RC:B1 / RC:C1 等〉
- 研究状态：〈GO / HOLD / FORK / END；未评估则写未标记〉
- 状态截至日期：〈YYYY-MM-DD〉
- 执行状态：〈可选，独立填写待开展/进行中/待复核/暂停/已结束〉
- 证据类别：〈有限数值筛查 / 模型或 surrogate 对照 / 实际 ζ 数值候选 / 严格证明或区间认证 / 初步观察〉
- 证据版本：〈仓库提交、运行标识、配置/源码哈希、原始证明或认证文件〉
- 论文位置：〈未来的节号、表号、图号；尚无论文时写待编排〉

## 发现与检验

1. 问题与假设：研究哪个对象、参数范围和可检验命题？
2. 线索与基线：发现什么异常；相对什么基线；为何值得追踪？
3. 检验过程：怎样复现、设置对照、排查误差或检验理论联系？
4. 结果与证据：具体效应、覆盖范围、失败情况、证明/认证内容与原始来源。
5. 解释边界：哪些命题被支持或排除；哪些仍未解决？有限未检出不得写成整个方向已排除。
6. 状态理由与下一步：为何 GO/HOLD/FORK/END；后续判别检验、恢复条件、分支关系或停止原因是什么？

此处仅有表头；填写真实记录后才能作为论文状态依据。状态变化不覆盖之前的结论。

## 论文中推荐的短标记

`〈方向〉 / 〈线索编号〉 / 〈节点〉 / 〈状态〉 · 截至〈日期〉`

短标记旁须能追溯证据和范围。GO 不能替代数学证明，END 不能替代严格排除，E1 不能替代 E2。论文汇总多个条目时，不将它们的不同状态合成为整个方向的完成百分比。
