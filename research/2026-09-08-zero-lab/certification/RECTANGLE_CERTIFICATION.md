# 严格矩形围道零点计数

日期：2026-09-08。实现版本：本地 python-flint 0.8.0，默认60位十进制精度（203 bits）。

## 1. 接口与本轮结果

[rectangle_count.py](rectangle_count.py) 提供

```python
count_rectangle(a, b, c, d,
                func="zeta", dps=60, max_depth=24,
                max_evaluations=50000, max_seconds=30.0,
                include_segments=True)
```

矩形为 `(a,b) × (c,d)`，输入十进制必须用字符串或精确有理数，禁止 Python float。精确路径是 `decimal string → Fraction → fmpq → arb/acb enclosure`；不会把用户给定十进制坐标先转换成二进制浮点数。官方文档也明确区分了 float 输入与精确有理输入，并说明区间比较只有在整个区间上成立时才返回 True。[python-flint 一般概念](https://python-flint.readthedocs.io/en/latest/general.html)

本轮校准均通过：

| 函数/矩形 | 状态 | 严格零点数 | 接受的整段数 |
|---|---|---:|---:|
| ζ；`[.49,.51] × [14.13,14.14]` | certified | 1 | 142 |
| ζ；`[.6,.8] × [14,15]` | certified | 0 | 90 |
| ζ；`[.500001,.500003] × [14.13472,14.13473]` | certified | 0 | 146 |
| 合成函数 `s−(.3+14i)`；`[.29,.31] × [13.99,14.01]` | certified，synthetic | 1 | 4 |
| 同一合成函数；零点恰在矩形左边界 | unresolved | 不返回计数 | 仅接受了部分边界 |
| ζ；矩形内包含极点1 | rejected | 不返回计数 | — |
| ζ；函数求值预算设为1 | unresolved | 不返回计数 | 0 |

前三个ζ围道计算分别约0.036秒、0.022秒和0.036秒。本轮所有 `off_line_certified` 均为 false。跨临界线的计数1只是围道计数器校准；合成函数的离线根永远不能触发 ζ 反例标记。

逐项结果及每段记录见 [certification_checks.json](certification_checks.json)，复算入口为 [run_checks.py](run_checks.py)。

## 2. 认证命题

设 f 在闭矩形邻域解析，边界按逆时针方向分成有限条精确线段。对每一段 L，假设得到一个**包含整条 f(L)** 的有限闭矩形 B，且 `0∉B`。再以严格区间算术求出端点商 `f(z_next)/f(z_start)` 的主辐角包络 A，并验证

\[
A\subset(-\pi,\pi).
\]

则该段真实的连续辐角增量包含在 A 内。所有段的增量之和除以2π得到的区间若只含一个整数 n，则矩形内部的零点总数（按重数计）恰为 n。

本实现对 ζ 预先排除了闭矩形内及边界上的唯一极点 s=1；合成线性函数处处解析。因此这里辐角原理给出零点数，不需要再加减极点数。未接受任何未声明解析性质的任意回调函数。

## 3. 证明：为什么整段排零足够

1. B 是凸紧集，且不含原点。由严格分离，可以把 B 放入某个以原点为边界基点的开半平面；因此 B 上存在连续辐角分支，其取值宽度严格小于π。
2. 真实像弧 f(L) 全部位于 B，所以它的连续辐角变化严格位于 `(-π,π)`。也可在 B 内把该像弧同伦到连接两个真实端点像的直线段，全程不会碰到原点。
3. 真实端点商的主辐角与这个增量模2π相同；二者又都在 `(-π,π)`，因此确实相等。端点商的严格 arg 区间于是包含真实增量。
4. 逆时针闭合边界上的所有真实增量相加，是一个整数乘以2π。区间加法和严格 π 包络保留这个整数对应的归一化值。
5. 当 `arb.unique_fmpz()` 证明归一化区间中只有一个整数时，该整数只能是边界像绕原点的真实绕数。最后由辐角原理得到零点数。

这一步依赖“整个线段的函数像排零”，不能用很多采样点的函数值都非零来替代。`unique_fmpz()` 也不是把近似数四舍五入：它只在区间里存在唯一整数时成功。

## 4. 程序如何满足假设

- 顶点精确设为 `(a,c) → (b,c) → (b,d) → (a,d) → (a,c)`，方向为 CCW，末点与起点是同一组有理数。
- 对每条水平/垂直子线段，以精确有理中点和半宽构造 acb 输入矩形，对**这个集合**调用 `.zeta()`。`acb` 本身使用实部和虚部分离的区间误差界，表示复平面矩形。[FLINT acb 数据类型](https://flintlib.org/doc/acb.html)
- 只有 `.is_finite()` 为真且 `.contains(0)` 为假，才接受整段像排零。否则二分该线段，直到证明成立或预算耗尽。
- 端点值、端点商都必须有限且排零。随后 `.arg()` 的区间必须严格小于 `arb.pi()` 并严格大于 `-arb.pi()`；跨过主辐角分支切口产生的宽区间不会被误当作小增量。官方文档把 arg 定义为主辐角的严格区间，并说明负实轴处的分支不连续。[FLINT acb_arg](https://flintlib.org/doc/acb.html#c.acb_arg)
- 每个被接受的段保存精确起止点、深度、整段像包络、辐角增量包络。总增量和归一化区间都由 arb 计算，最后要求唯一整数。
- 精度上下文在结束时恢复；同一个 Python 进程内应串行调用，或将并行任务放入独立进程。

## 5. 何时允许说找到了离线 ζ 零点

只有以下条件**同时**满足，返回值才设置 `off_line_certified=True`：

1. `func="zeta"`，不是合成函数；
2. 围道状态 `certified`，零点数严格大于0；
3. 精确矩形完全位于 `0<a<b<1` 与 `0<c<d`；
4. `b<1/2` 或 `a>1/2`，整个闭矩形与临界线有严格正距离。

包含或碰触临界线的矩形即使计数为1也不触发离线结论。合成函数校准即使根位于0.3+14i，也明确标记 `synthetic=True`，并固定 `off_line_certified=False`。

## 6. 失败状态与可复算边界

`unresolved` 表示当前精度/细分/时间预算不足以证明边界排零或整数唯一性；它既不是“有零点”，也不是“没有零点”。边界某点恰为零时，算法应停在这个状态。极点1落入闭矩形则预先 `rejected`，避免把零点减极点的计数误当零点数。

JSON 中的区间是显示字符串，原始决策发生在内存 Arb 对象上。记录用于审查和复算；没有把这些字符串及布尔字段包装成可脱离程序与数值库独立验证的形式化证明对象。本结果依赖所用 FLINT/Arb 实现及本程序的正确性，没有声明经过证明助手形式化验证。
